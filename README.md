# Curling Game

Description: This was one of my smaller projects; a small, simple physics-based game that simulates curling

Controls: /n
Hold Space - Aim/Charge Power /n
Release Space - Launch /n
A (while holding space) - Aim Left /n
D (while holding space) - Aim Right /n
Left/Right Arrow (while holding space) - Adjust Curl Force /n
R - Restart
